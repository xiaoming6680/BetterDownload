# BetterDownload 0.4.1 验证记录

## 自动化验证

- Windows .NET Framework 编译通过，NuGet TagLibSharp 依赖包 SHA256 校验通过。
- 13 项 Node 测试覆盖下载事件、路径限制、FLAC/MP3 音频帧保持、内嵌封面与中文标签、重复任务、同名文件保护、损坏文件、文件锁、取消清理、心跳过期和后台启停。
- 测试音频为原创一秒正弦波；独立剥离输出标签后比对编码帧，与输入一致。
- Edge + Playwright 界面回归覆盖单按钮启停、无目录输入、270px 卡片、小型文件夹入口、自动隐藏、键盘焦点、打开文件夹后的焦点释放、窗口失焦、卸载清理和窄窗口布局。
- 毛玻璃背景为 62% 不透明底色与 28px 模糊；高对比度或减少透明效果时使用实色背景。

## 客户端信息

设置页已在 BetterNCM 1.3.4 正常显示。下载回调接口对照网易云 3.1.37 前端资源核对；源码核对和模拟测试不代表完整客户端下载链路已经验收。

真实 NCM 下载的 FLAC/MP3 转换、完整歌曲播放、多个并发任务和其他插件兼容性仍需按 [发布流程](PUBLISHING.md) 验收。普通音频无需转换。

## 云端构建

每次 Actions 构建会生成 `build-info.json` 与 `SHA256SUMS.txt`，记录源码提交、构建地址及文件哈希。查看 [Actions](https://github.com/xiaoming6680/BetterDownload/actions) 获取实际构建状态。
